# Dead Air x64 — HD-текстуры

Набор текстур **Stalker Two-K** высокого разрешения для [Dead Air x64](https://github.com/DeadAir-x64/DeadAir-x64-Update).

Автор набора — **Akinaro**. Страница набора: <https://www.moddb.com/mods/stalker-two-k>

Набор выкладывается **без изменений**, ровно в том виде, в каком его выпустил автор.

---

## Зачем это здесь

В readme автора есть строчка, ради которой всё и затевалось:

> Эта версия рассчитана на слабо модифицированные игры, на других мододелов и на будущие версии Сталкера с 64-битным движком, который потянет такие текстуры.

Такой движок теперь есть. На x32 набор упирался в потолок адресного пространства и валил игру ошибкой нехватки памяти; на x64 он просто работает.

## Два набора на выбор

Заменяется около 75% текстур окружения — 18 разделов: бетон, металл, камень, стены, кирпич, дерево, земля, двери, полы, окна, плитка, крыши, стекло, вода, техника, реквизит и слой деталей. Файлы в обоих наборах одни и те же, отличается разрешение части из них.

| | Полный | Облегчённый |
|---|---|---|
| Загрузка | 2.68 ГБ, 4 части | 1.96 ГБ, 3 части |
| На диске | 4.0 ГБ | 2.9 ГБ |
| Видеопамять сверх штатной | +640 МБ | +470 МБ |

**Разница меньше, чем можно подумать.** Из 1553 текстур в облегчённом уменьшены вдвое только **234**; остальные 1316 — те же самые файлы. В основном ужаты 2048 → 1024 (163 штуки) и 4096 → 2048 (52). Поэтому облегчённый весит 73% от полного, а не половину.

Разрешение полного набора: 742 текстуры в 2048px, 397 в 1024px, 123 в 4096px и одна — асфальт слоя деталей — 8192×8192. Название «Two-K» — заявление автора, а не факт по каждому файлу; всё крупнее 2048px даёт 27% объёма.

## Что выбрать

Установщик определяет видеопамять сам и советует. Пороги взяты из замера в живой игре: полный набор на 1080p занимает 2190 МБ видеопамяти, пик 2905 МБ.

| Видеопамять | Совет |
|---|---|
| 8 ГБ и больше | полный, с запасом |
| 6 ГБ | облегчённый; полный пойдёт только на 1080p |
| 4 ГБ | облегчённый |
| меньше 4 ГБ | не ставить |

На частоту кадров наборы влияют слабо: разрешение текстур не меняет объём работы на кадр, оно меняет объём занятой памяти. Просадки начинаются только тогда, когда память кончилась и драйвер принимается гонять текстуры туда-сюда.

Апскейлер здесь не помощник: он уменьшает буферы кадра, а не текстуры — те лежат в памяти целиком независимо от разрешения.

## Установка

**Проще всего — установщиком.** Скачайте `DeadAir-x64-HD-installer.zip` из [последнего выпуска](../../releases/latest), положите оба файла из архива в корень установленной игры (рядом с `bin` и `database`) и запустите `HD-текстуры.cmd`.

Он сам возьмёт нужный выпуск, скачает четыре части, проверит контрольные суммы и распакует. Каждая часть удаляется сразу после распаковки, поэтому на диске в моменте лежит меньше гигабайта загрузки, а не 2.7 ГБ.

Оборвалась связь — просто запустите ещё раз: докачается остаток той части, на которой встало, уже поставленные не перекачиваются.

Тем же установщиком набор **снимается**: запустите его повторно и выберите «снять набор». Файлы игры, которые набор перекрыл, вернутся на место — при установке они уносятся в резерв.

### Вручную

Файлы раздаются **вложениями выпусков** — на вкладке [Releases](../../releases), а не в самом репозитории. Так сделано намеренно: 4 ГБ двоичных файлов в истории git превратили бы клонирование репозитория в бедствие.

Скачайте все части выбранного набора (полный — `DeadAir-x64-HD-<n>of4`, облегчённый — `DeadAir-x64-HD-lite-<n>of3`), положите в корень игры и распакуйте каждую:

```
tar -xf DeadAir-x64-HD-1of4.tar.xz
tar -xf DeadAir-x64-HD-2of4.tar.xz
tar -xf DeadAir-x64-HD-3of4.tar.xz
tar -xf DeadAir-x64-HD-4of4.tar.xz
```

`tar` входит в состав Windows 10 (сборка 1803 и новее) и Windows 11 — ставить ничего не нужно. На Windows 7 распакуйте любым архиватором, понимающим `.tar.xz`, например 7-Zip; установщик там не сработает и честно об этом скажет.

Части независимы: порядок распаковки не важен, и каждая пригодна сама по себе, если какая-то не докачалась.

Проверить, что файлы дошли целыми:

```
certutil -hashfile DeadAir-x64-HD-1of4.tar.xz SHA256
```

Значения — в файле `SHA256SUMS.txt` того же выпуска.

## Удаление

Установщик снимает набор сам. Если ставили вручную — перечень всех файлов набора лежит в `FILES.txt` выпуска, по нему их можно удалить, не задев остальное.

## Условия автора

Набор отдан сообществу бесплатно. Разрешение включать его в другие моды дано при условиях:

1. Автора уведомляют об использовании — по почте `akinaro@onet.eu` или любым другим способом.
2. В описании мода указывают его имя и то, что именно использовано.
3. Текстуры остаются бесплатными: за них нельзя брать деньги, включая добровольные пожертвования.
4. Использовать их можно только с играми серии S.T.A.L.K.E.R.

Изменять содержимое набора без уведомления автора и без предупреждения пользователей о правках нельзя. Автор оставляет за собой право отозвать разрешение, если условия не выполняются.

Все четыре условия здесь соблюдены: набор выложен без изменений, бесплатно, для S.T.A.L.K.E.R., с указанием авторства.

Все текстуры сделаны автором из свободных исходных изображений в свободных графических редакторах.
